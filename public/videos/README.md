# Vídeo do hero da Qualidade Veículos

Coloque nesta pasta o vídeo institucional original com o nome exato:

`institucional.mp4`

O arquivo será servido pela Vercel em `/videos/institucional.mp4` e exibido no hero da página inicial.

Importante: não é necessário editar HTML ou CSS após enviar o arquivo. O visual usa vídeo vertical, mantém a proporção 9:16 e começa sem som por exigências dos navegadores. Para um carregamento mais rápido, considere criar uma versão comprimida (H.264, sem aumento de resolução).
